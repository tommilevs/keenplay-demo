# keenplay-demo

Reference Playkeen application for Entware/Keenetic. This repository demonstrates the public `playkeen.yaml` contract and Release-based delivery.

## Русский

Эталонное приложение Playkeen для Entware/Keenetic. Репозиторий демонстрирует публичный контракт `playkeen.yaml` и доставку через GitHub Release.
