# keenplay-demo

Reference Unixplay application for Entware/Keenetic. This repository demonstrates the public `unixplay.yaml` contract and Release-based delivery.

## Русский

Эталонное приложение Unixplay для Entware/Keenetic. Репозиторий демонстрирует публичный контракт `unixplay.yaml` и доставку через GitHub Release.
